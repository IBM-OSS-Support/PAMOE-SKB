**PAMOE-SKB – IBM Release**

This package contains the PAMOE-SKB runtime along with all 8 IBM Banking Automated Workflows.
When you run the provided docker-compose file, a repos/ folder is automatically created and populated with all workflows, including database initialization scripts.

To start the environment, follow the official PAMOE-SKB documentation.

For MCP-related setup and usage, refer to the bamoe-mcp folder included in this release.

**Official documentation:**
https://ibm.com/docs/en/pamoeskb/9.4.x
